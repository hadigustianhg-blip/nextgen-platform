# NEXTGEN UI Assets

Paket ini berisi aset awal untuk redesign dashboard NEXTGEN.

## Isi
- Logo horizontal versi light/dark
- Logo mark N
- Wordmark
- Favicon dan app icon
- Ilustrasi sidebar
- Empty-state illustrations
- Avatar default
- Background pattern
- Brand tokens dan CSS variables
- Design guideline untuk Codex
- Screenshot referensi

## Catatan
SVG memakai font fallback sistem (`Inter, Arial, sans-serif`) dan tidak menyertakan file font.
PNG icon dibuat dari mark yang sama agar konsisten.
